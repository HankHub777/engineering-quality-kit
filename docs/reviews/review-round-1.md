Severity: high

**Commits**: `2733d3a` fix(A-3): revert refuses manifest paths outside the repository

**Fix**: Before touching a path, revert requires the manifest path to be relative and `p.resolve()` to be inside `root.resolve()`. Otherwise the entry goes to `kept` with reason `path outside repository; refusing`. This applies even with `--force`.

**Before fix**: 1st run FAILED: the log contained `timed out after 3s\nb'started\n'`. After the decode fix, 2nd run FAILED: `child process of a timed-out check is still running`.
